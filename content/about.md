## Over deze demo is nieuw

Deze site laat een eenvoudige werkwijze zien voor het met Hugo bouwen en op Github hosten van een website:

1. Schrijf de inhoud in Markdown.
2. Bekijk je wijzigingen lokaal met `hugo server -D`.
3. Ben je tevreden met je wijzigingen? Commit en push ze dan naar GitHub.
4. Bij elke push naar `main` bouwt een GitHub Actions-workflow de site en
   publiceert die op GitHub Pages.

Er is ook een pagina [Aanmelden]({{< relref "signup-formspree.md" >}}). Die laat zien hoe een statische site kan
samenwerken met een externe formulierdienst, in dit geval
[Formspree](https://formspree.io/), die de inzendingen ontvangt en opslaat.
Op deze manier kun je eenvoudige formulieren verwerken zonder eigen servercode.

De hele website code, inclusief theme en workflow is open source en te vinden
op GitHub onder [github.com/tonvanbart/hugo-demo](https://github.com/tonvanbart/hugo-demo).
